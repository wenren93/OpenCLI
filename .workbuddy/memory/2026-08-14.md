# 2026-08-14 工作日志

## 即刻动态流 HTML 报告脚本
- 新增 `scripts/jike_feed_report.py`：调用 `opencli jike feed -f json --window background --keep-tab false` 拉取即刻首页动态，按「近 N 小时（默认 4）」过滤，保留 作者/时间/内容/链接 四项，生成卡片式 HTML 报告。
- 关键点：opencli 的 node warning 走 stderr，stdout 为纯 JSON；feed 时间字段为 UTC ISO8601，脚本统一转北京时区展示。
- feed 无时间窗口参数，仅 `--limit`；脚本默认 limit=100 并在命中窗口末条时提示截断、建议增大 limit。
- 支持参数：`--hours` `--limit` `--output` `--timeout`；HTML 输出到 `scripts/output/`（已加入 .gitignore）。
- 实测拉取 100 条、近 4 小时命中 7 条，生成 `scripts/output/jike-feed-20260814-013040.html`。
